# 16. Testing — Strategi Testing

> Dokumen ini menjabarkan strategi dan skenario testing untuk MVP 32 hari. Fokusnya proporsional: unit test untuk logika kritis, manual QA untuk flow end-to-end, bukan coverage 100% yang tidak realistis untuk timeline ini. Dibaca bersama `15. Security.md` (security test cases) dan `13. AI.md` (AI testing scenarios).

---

## 16.1 Filosofi Testing MVP

Tiga prinsip yang menjaga testing tetap efektif tanpa menjadi beban:

1. **Test logika, bukan implementasi.** Yang butuh test adalah *apa* yang dilakukan kode (proyeksi saldo, kalkulasi recurring), bukan *bagaimana* caranya (apakah pakai loop atau reduce). Test yang terlalu terikat implementasi akan sering patah saat refactor, menambah biaya tanpa nilai.

2. **Logika kritikal keuangan = unit test wajib.** Bug di proyeksi saldo atau recurring bill generator langsung berdampak ke user — ini bukan tempat "QA manual saja cukup". Sebaliknya, UI state management tidak perlu unit test menyeluruh untuk MVP.

3. **Manual QA untuk flow, automated test untuk kalkulasi.** End-to-end testing framework penuh (Playwright/Cypress) bagus tapi setup-nya memakan waktu signifikan. Untuk 32 hari, manual QA dengan skenario terdokumentasi lebih efisien — tapi semua kalkulasi finansial harus automated.

## 16.2 Testing Pyramid MVP

```
         ▲
        /E2E\        ← Manual QA (skenario terdokumentasi di 16.6)
       /─────\
      /Integ. \      ← API integration test (Jest + Supertest, Section 16.5)
     /─────────\
    / Unit Test \    ← Wajib untuk logika kritis (Jest, Section 16.3–16.4)

```

**Target coverage MVP (realistis, bukan aspirasional):**
- Unit test: logika kritikal wajib 100% (recurring engine, forecast, saldo kalkulasi)
- Integration test: happy path + 1 error case per API route utama
- E2E: manual, skenario lengkap di Section 16.6

## 16.3 Unit Test — Recurring Bill Generator

Ini unit test paling kritis di seluruh codebase. Bug di sini menyebabkan Calendar menampilkan tagihan di tanggal yang salah — langsung terlihat oleh semua user.

```typescript
// __tests__/recurring-engine.test.ts
import { generateOccurrences, normalizeDate } from '@/lib/recurring-engine';

describe('Recurring Bill Generator', () => {

  describe('Monthly recurring — edge cases tanggal', () => {
    it('tanggal 31 di bulan yang punya 31 hari → tetap tanggal 31', () => {
      const rule = { dayOfMonth: 31, startDate: new Date('2026-01-01') };
      const occurrences = generateOccurrences(rule, new Date('2026-03-01'), 31);
      expect(occurrences[0].date.getDate()).toBe(31);  // Maret punya 31 hari
    });

    it('tanggal 31 di bulan April (30 hari) → mundur ke tanggal 30', () => {
      const rule = { dayOfMonth: 31, startDate: new Date('2026-01-01') };
      const occurrences = generateOccurrences(rule, new Date('2026-04-01'), 30);
      expect(occurrences[0].date.getDate()).toBe(30);  // April hanya 30 hari
    });

    it('tanggal 29 Februari di tahun bukan kabisat → mundur ke 28', () => {
      const rule = { dayOfMonth: 29, startDate: new Date('2025-01-01') };
      const occurrences = generateOccurrences(rule, new Date('2025-02-01'), 28);
      expect(occurrences[0].date.getDate()).toBe(28);  // 2025 bukan tahun kabisat
    });

    it('tanggal 29 Februari di tahun kabisat → tetap 29', () => {
      const rule = { dayOfMonth: 29, startDate: new Date('2024-01-01') };
      const occurrences = generateOccurrences(rule, new Date('2024-02-01'), 29);
      expect(occurrences[0].date.getDate()).toBe(29);  // 2024 adalah tahun kabisat
    });

    it('tanggal 30 di Februari → mundur ke 28 (atau 29 di tahun kabisat)', () => {
      const rule = { dayOfMonth: 30, startDate: new Date('2026-01-01') };
      const occurrences = generateOccurrences(rule, new Date('2026-02-01'), 28);
      expect(occurrences[0].date.getDate()).toBe(28);
    });
  });

  describe('Duplikasi prevention', () => {
    it('menjalankan generator dua kali tidak menghasilkan occurrence duplikat', async () => {
      const rule = { id: 'rule-1', dayOfMonth: 15 };
      await generateOccurrences(rule, 60);
      await generateOccurrences(rule, 60);  // run kedua kali

      const { data: occurrences, error } = await supabase
        .from('calendar_events')
        .select('*')
        .eq('recurring_rule_id', rule.id);
      expect(error).toBeNull();

      // Setiap tanggal hanya boleh muncul sekali
      const dates = occurrences.map(o => o.dueDate.toISOString());
      const uniqueDates = new Set(dates);
      expect(dates.length).toBe(uniqueDates.size);
    });
  });

  describe('Range generation', () => {
    it('menghasilkan occurrence untuk tepat 60 hari ke depan', () => {
      const rule = { dayOfMonth: 10 };
      const fromDate = new Date('2026-07-01');
      const toDate = new Date('2026-08-30');  // 60 hari kemudian
      const occurrences = generateOccurrences(rule, fromDate, toDate);

      occurrences.forEach(o => {
        expect(o.date >= fromDate).toBe(true);
        expect(o.date <= toDate).toBe(true);
      });
    });

    it('tagihan dengan startDate di masa depan tidak menghasilkan occurrence sebelum startDate', () => {
      const rule = {
        dayOfMonth: 5,
        startDate: new Date('2026-09-01'),  // mulai September
      };
      const occurrences = generateOccurrences(rule, new Date('2026-07-01'), new Date('2026-08-31'));
      expect(occurrences).toHaveLength(0);
    });
  });
});
```

## 16.4 Unit Test — Forecast Engine & Saldo Kalkulasi

```typescript
// __tests__/forecast-engine.test.ts
import { computeForecast, computeRunningBalance } from '@/lib/forecast-engine';

describe('Forecast Engine', () => {

  describe('computeRunningBalance', () => {
    it('kalkulasi saldo dasar: saldo awal + income - expense', () => {
      const initialBalance = 5_000_000;
      const transactions = [
        { amount: 8_000_000, type: 'income', date: new Date('2026-07-25') },
        { amount: -1_500_000, type: 'expense', date: new Date('2026-07-01') },
        { amount: -850_000, type: 'expense', date: new Date('2026-07-10') },
      ];

      const balance = computeRunningBalance(initialBalance, transactions, new Date('2026-07-31'));
      expect(balance).toBe(5_000_000 + 8_000_000 - 1_500_000 - 850_000);  // 10.650.000
    });

    it('saldo negatif diizinkan (bukan error)', () => {
      const initialBalance = 100_000;
      const transactions = [
        { amount: -500_000, type: 'expense', date: new Date('2026-07-05') },
      ];

      const balance = computeRunningBalance(initialBalance, transactions, new Date('2026-07-10'));
      expect(balance).toBe(-400_000);  // negatif valid
      expect(balance).toBeLessThan(0);
    });

    it('transaksi di tanggal yang sama dengan target dihitung', () => {
      const initialBalance = 1_000_000;
      const targetDate = new Date('2026-07-15');
      const transactions = [
        { amount: -200_000, type: 'expense', date: targetDate },  // same day
      ];

      const balance = computeRunningBalance(initialBalance, transactions, targetDate);
      expect(balance).toBe(800_000);
    });

    it('transaksi setelah target date tidak dihitung', () => {
      const initialBalance = 1_000_000;
      const transactions = [
        { amount: -500_000, type: 'expense', date: new Date('2026-08-01') },  // future
      ];

      const balance = computeRunningBalance(initialBalance, transactions, new Date('2026-07-31'));
      expect(balance).toBe(1_000_000);  // future transaction tidak masuk
    });
  });

  describe('computeForecast', () => {
    it('cold start (tanpa histori) menghasilkan proyeksi dari scheduled items saja', () => {
      const context = {
        currentBalance: 3_000_000,
        scheduledIncome: [{ amount: 8_000_000, date: new Date('2026-07-25') }],
        scheduledBills: [{ amount: 1_500_000, date: new Date('2026-07-01') }],
        historicalAvgDailyExpense: 0,  // cold start — tidak ada histori
      };

      const forecast = computeForecast(context, 30);

      // Hari sebelum gajian: 3.000.000 - 1.500.000 = 1.500.000
      expect(forecast.find(d => d.date.getDate() === 10)?.projectedBalance).toBe(1_500_000);
      // Setelah gajian masuk tgl 25: + 8.000.000
      expect(forecast.find(d => d.date.getDate() === 26)?.projectedBalance).toBe(9_500_000);
    });

    it('mendeteksi dan menandai hari dengan proyeksi saldo negatif pertama kali', () => {
      const context = {
        currentBalance: 500_000,
        scheduledIncome: [{ amount: 8_000_000, date: new Date('2026-07-25') }],
        scheduledBills: [
          { amount: 800_000, date: new Date('2026-07-05') },
        ],
        historicalAvgDailyExpense: 150_000,  // rata-rata harian
      };

      const forecast = computeForecast(context, 30);
      const negativeDay = forecast.find(d => d.projectedBalance < 0);

      expect(negativeDay).toBeDefined();
      expect(negativeDay?.isNegativeAlert).toBe(true);
    });

    it('tidak menghasilkan proyeksi lebih dari 60 hari', () => {
      const context = { currentBalance: 1_000_000, scheduledIncome: [], scheduledBills: [], historicalAvgDailyExpense: 0 };
      const forecast = computeForecast(context, 90);  // minta 90 hari
      expect(forecast.length).toBeLessThanOrEqual(60);  // dibatasi 60 hari
    });
  });
});
```

## 16.5 Integration Test — API Routes

Integration test memverifikasi bahwa API route berperilaku benar end-to-end, termasuk autentikasi dan isolasi data. Test memakai Supabase client (`supabase`) terhadap database test nyata (bukan mock) — session user di-mock agar RLS aktif dan policy benar-benar diuji.

```typescript
// __tests__/api/transactions.test.ts
import { createMocks } from 'node-mocks-http';
import { POST, GET } from '@/app/api/transactions/route';

describe('POST /api/transactions', () => {
  it('401 jika tidak ada session', async () => {
    const { req } = createMocks({ method: 'POST' });
    const response = await POST(req);
    expect(response.status).toBe(401);
  });

  it('400 jika payload tidak valid (amount negatif)', async () => {
    const { req } = createMocks({
      method: 'POST',
      body: { amount: -100, type: 'income', walletId: 'valid-uuid', transactionDate: new Date().toISOString() },
    });
    mockSession(req, { userId: 'user-1' });
    const response = await POST(req);
    expect(response.status).toBe(400);
  });

  it('403 jika walletId bukan milik workspace user', async () => {
    const { req } = createMocks({
      method: 'POST',
      body: { amount: 100_000, type: 'expense', walletId: 'wallet-user-lain', transactionDate: new Date().toISOString(), categoryId: 'cat-food' },
    });
    mockSession(req, { userId: 'user-1' });
    const response = await POST(req);
    expect(response.status).toBe(403);
  });

  it('201 dan memperbarui saldo wallet setelah transaksi berhasil', async () => {
    // Setup: buat user, workspace, wallet di DB test
    const { user, workspace, wallet } = await setupTestWorkspace();

    const { req } = createMocks({
      method: 'POST',
      body: {
        amount: 500_000,
        type: 'expense',
        walletId: wallet.id,
        workspaceId: workspace.id,
        categoryId: 'cat-food',
        transactionDate: new Date().toISOString(),
      },
    });
    mockSession(req, { userId: user.id });

    const response = await POST(req);
    expect(response.status).toBe(201);

    // Verifikasi saldo wallet berkurang
    const { data: updatedWallet } = await supabase
      .from('wallets')
      .select('*')
      .eq('id', wallet.id)
      .single();
    expect(updatedWallet?.cachedBalance).toBe(wallet.initialBalance - 500_000);
  });
});
```
